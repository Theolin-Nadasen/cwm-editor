# Memes

Drop reaction images, gifs and short clips here. `cwmeditor meme` accepts any path, so this folder is just the default home for the ones you reuse.

```
memes/
  shocked.png
  record-scratch.mp4
  this-is-fine.gif
```

Guidelines:

- **Images** (PNG, WEBP, JPG) work best. Transparent PNGs look cleanest over footage.
- **Clips** should be short and silent. Sound stingers are a later milestone.
- **Size**: roughly square or 16:9. The overlay scales to `--scale` of the frame width, so very tall images will look small.
- **Naming**: describe the reaction, not the source. `shocked`, `record-scratch`, `nope`, `chefs-kiss`.

On sourcing: Tenor's API shut down in June 2026, and Giphy library content is not licensed for commercial video use. For a monetised channel the safe options are reaction clips you record yourself, royalty-free footage from Pexels or Pixabay, or reaction images generated with the image model. Keep a `source.txt` note per file if a licence matters.
